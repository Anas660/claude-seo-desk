# Code of conduct

SEO Desk is built by people with different backgrounds, languages and levels of experience. Everyone who takes part
(in issues, pull requests, discussions or anywhere else this project lives) is expected to:

- be respectful and patient, and assume good faith;
- give and take criticism about code and ideas, never about people;
- welcome newcomers and first contributions;
- keep discussions on topic.

Not acceptable: harassment, personal attacks, discriminatory language or imagery, sexual content, publishing someone's
private information, or sustained disruption.

The maintainer may edit or remove comments, commits and issues that break these rules, and may block people who
keep breaking them. To report something, contact [@Anas660](https://github.com/Anas660) on GitHub privately; reports
are handled confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
